# PR service

Сервис, который автоматически назначает ревьюеров на Pull Request’ы (PR), а также позволяет управлять командами и участниками. Взаимодействие происходит исключительно через HTTP API.

## Установка и запуск
1.  Необходимы `docker` и `docker-compose`.
2.  Скачать проект.
3.  Из корня проекта выполнить:
    `make build`
    `make up`
    Сервис будет доступен по адресу `http://localhost:8080`.

## Остановка
1.  Из корня проекта выполнить:
    `make down`

## Очистка
1.  Из корня проекта выполнить:
    `make clean`


## Принятые решения 

*Логика `POST /team/add`:*
При добавлении пользователя в новую команду через `POST /team/add`, он автоматически удаляется из его старой команды. Это обеспечивает согласованность данных. При этом, пользователи, переданные в `members`, обновляются в таблице `users` (`is_active`, `team_name`), остальные показатели не изменяются.
Если команда с указанным `team_name` уже существует, возвращается ошибка `400 TEAM_EXISTS`. Назначение в старую команду не производится.

*Сообщение об ошибке `404` в `GetTeamGet`:* 
Для случая, когда команда не найдена, используется сообщение `"team_name not found"`, хотя в спецификации это не указано явно.

*Уникальность `Pull Request`:* 
В `POST /pullRequest/create` проверяется уникальность как `pull_request_id`, так и `pull_request_name`. Если любой из них уже существует, возвращается ошибка `409 PR_EXISTS`.
