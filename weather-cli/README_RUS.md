# Weather CLI

Простое погодное приложение командной строки, написанное на Go. 
Оно автоматически определяет ваше местоположение или принимает название города, затем извлекает и отображает прогноз погоды из [wttr.in](https://wttr.in).

## Функции
- Автоматическое определение местоположения по IP
- Ввод города вручную
- Настраиваемый формат вывода (1-4)
- Чистый, читаемый вывод с поддержкой ANSI / погодных символов
- Модульно протестированный код

#### 1. Запуск с настройками по умолчанию (автоматическое определение местоположения)
`go run main.go`

#### 2. Укажите город
`go run main.go -city <ваш_город>`

Пример: `go run main.go -city London`

#### 3. Измените формат вывода
Формат 1: Краткое описание (по умолчанию)
`go run main.go -format 1`

Формат 2:
`go run main.go -format 2`

Формат 3: 
`go run main.go -format 3`

Формат 4: 
`go run main.go -format 4`

#### 4. Объедините город и формат
Вы можете использовать оба флага вместе:
`go run main.go -city <ваш_город> -format <нужный_формат>`

Пример: `go run main.go -city London -format 4`
