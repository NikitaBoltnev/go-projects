# Project 02 — Go_Bootcamp

## Проект «Конкурентное выполнение»

### Реализация 1. Секундомер асинхронных задач

Реализована программа для измерения времени выполнения конкурентных горутин:

- Чтение параметров N и M из аргументов командной строки
- Запуск N горутин, каждая из которых "спит" случайное время до M миллисекунд
- Использование sync.WaitGroup для ожидания завершения всех горутин
- Сбор и сортировка результатов по времени сна в порядке убывания
- Вывод пар: <номер горутины, время сна>

**Особенности реализации:**
- Без использования каналов (как требовалось)
- Корректная синхронизация с WaitGroup
- Генерация случайного времени сна
- Алгоритм сортировки результатов

### Реализация 2. Генератор квадратов чисел

Построен конкурентный конвейер для обработки чисел:

- Генератор чисел от K до N с отправкой в канал 1
- Функция возведения в квадрат с чтением из канала 1 и отправкой в канал 2
- Основная программа выводит результаты из канала 2
- Оба процесса работают конкурентно

**Особенности реализации:**
- Правильное закрытие каналов после завершения работы
- Ограничения на операции чтения/записи каналов
- Последовательная обработка чисел
- Конкурентное выполнение генератора и обработчика

### Реализация 3. Тикер с обработкой сигналов

Создан асинхронный тикер с поддержкой graceful shutdown:

- Параметр K задает шаг тикера в секундах
- Вывод сообщений "Tick <i> since <time>" с номером тика и временем
- Обработка сигналов SIGTERM и SIGINT для graceful termination
- Вывод сообщения "Termination" при завершении

**Особенности реализации:**
- Использование signal.Notify для обработки сигналов
- Асинхронная работа тикера
- Корректное завершение по сигналам ОС
- Без использования time.After или time.Ticker

### Реализация 4. LRU-Cache с использованием Generics (бонус)

Реализован потокобезопасный LRU-кэш с дженериками:

- Конструктор принимает тип элементов и емкость кэша
- Методы Set, Get, Clear с сложностью O(1)
- Алгоритм LRU с вытеснением редко используемых элементов
- Потокобезопасность для работы из multiple горутин

**Особенности реализации:**
- Использование дженериков для типобезопасности
- Double-linked list + hash map для эффективности O(1)
- Mutex для обеспечения потокобезопасности
- Полное покрытие тестами всех сценариев работы

Все реализации используют только стандартную библиотеку Go.
