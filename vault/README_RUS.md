# Vault — Безопасный менеджер паролей

Зашифрованный менеджер паролей CLI, написанный на Go. 
Данные учетной записи хранятся в зашифрованном файле ("data.vault") с использованием AES-256.

## Основные возможности
- Создание, поиск и удаление учетных записей
- Шифрование данных с помощью секретного ключа
- Храните зашифрованные данные в "data.vault`
- Считывайте ключ из `.env` или переменных окружения
- Красочный CLI-интерфейс

## Как запустить

### 1. Устанавливаем зависимости
`go mod tidy`

### 2. Настраиваем ключ шифрования
Вы должны предоставить шестнадцатеричный ключ из 64 символов (32 байта) для AES-256.

Вариант A: Используйте файл .env (рекомендуется).

`echo "KEY=your_32_char_hex_key_here" > .env`

Вы можете сгенерировать ключ через терминал (Linux/macOS):
`openssl rand -hex 32`

В качестве альтернативы вы можете сгенерировать ключ AES-256 на специальных веб-сайтах. Но это небезопасная практика.

Пример добавления ключа:
`echo "KEY=bf19575b7a4bd0302f587c3a19d8bf3a9ed077fcb9706a6a1c775079a463f37f" > .env`

Старый файл зашифрованный с помощью предыдущего ключа и не может быть расшифрован с помощью нового.
Если вы решите изменить ключ, вы должны сначала удалить файл `data.vault`, который содержит зашифрованные данные и создается после сохранения вашей учетной записи. 
В противном случае программа не будет запущена со старым зашифрованным файлом и новым ключом. 

Удаление `data.vault` приведет к удалению всех сохраненных учетных записей. 

Вариант B: Установите переменную окружения во время запуская кода 

`KEY=your_32_char_hex_key_here go run main.go`

В случае использование данного варианта, вам придется при каждом запуске указывать ключ AES-256. Если вы решите заменить ключ, не забывайте удалять файл `data.vault`. 

### 3. Запускаем приложение

`go run main.go`
