
# Project 01 — Go_Bootcamp

### Реализация 1. Консольный калькулятор

Реализован интерактивный консольный калькулятор с поддержкой основных арифметических операций:

- Поддерживаемые операции: сложение, вычитание, умножение, деление
- Операнды обрабатываются как числа с плавающей точкой (float64)
- Точность вычислений при делении — 3 знака после запятой
- Реализована валидация ввода данных с обработкой некорректных значений
- При ошибках ввода программа выводит сообщение "Invalid input" и запрашивает данные повторно

**Пример работы:**

```
Input left operand: 
> 10.5
Input operation: 
> *
Input right operand: 
> 2
Result: 21.000
```

### Реализация 2. Анализатор частоты слов

Программа для анализа текста и определения наиболее часто встречающихся слов:

- Принимает на вход строку текста и число K
- Подсчитывает частоту встречаемости каждого слова в строке
- Возвращает K наиболее частых слов, отсортированных по убыванию частоты
- При одинаковой частоте слова сортируются лексикографически
- Обрабатывает краевые случаи: пустые строки, K больше количества уникальных слов
- Разделитель слов — пробел

**Пример работы:**

```
Входные данные: "aa bb cc aa cc cc cc aa ab ac bb"
K: 3
Результат: cc aa bb
```

### Реализация 3. Поиск пересечения коллекций

Утилита для нахождения пересечения двух наборов чисел:

- Считывает два списка целых чисел, разделенных пробелами
- Находит общие элементы в обоих списках
- Сохраняет порядок элементов из первого списка
- Обрабатывает ошибки ввода (нечисловые значения)
- Возвращает "Empty intersection" при отсутствии общих элементов

**Пример работы:**

```
Первый список: 5 3 4 2 1 6
Второй список: 6 4 2 4
Результат: 4 2 6
```

### Реализация 4. Система учета посещений

Интерактивная система для ведения журнала медицинских посещений:

**Поддерживаемые команды:**

- **Save** — сохранение информации о визите (ФИО пациента, специализация врача, дата)
- **GetHistory** — просмотр полной истории посещений пациента
- **GetLastVisit** — получение даты последнего визита к конкретному специалисту

**Особенности реализации:**

- Хранение данных в памяти с использованием структур map
- Формат даты: YYYY-MM-DD
- Обработка ошибок (PatientNotFoundError при отсутствии пациента)
- Интерактивный режим работы без перезапуска программы

**Пример использования:**

```
Save
Иванов Иван Иванович
ортопед
2024-04-13

GetHistory
Иванов Иван Иванович
Результат: ортопед 2024-04-13
```

Все реализации выполнены с использованием только стандартной библиотеки Go.
