# Guestbook HTTP

Простое веб-приложение на Go, которое позволяет пользователям оставлять подписи в гостевой книге.  
Подписи сохраняются в текстовом файле: `data/signatures.txt`.

## Возможности
- Просмотр списка всех подписей
- Добавление новой подписи через веб-форму
- Простое хранение данных в файле

## Как запустить
`go run main.go`
Откройте в браузере: http://localhost:8080/guestbook
