# Консольный менеджер закладок

Простое приложение в командной строке на Go, которое позволяет управлять закладками в виде пар «ключ-значение».

## Возможности
- Просмотр всех закладок
- Добавление новой закладки (ключ и значение)
- Удаление закладки по ключу
- Удобный интерфейс с меню

## Как запустить
`go run main.go`
