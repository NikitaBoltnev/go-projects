# Mini Projects Collection

A collection of small Go programs and experiments that don't warrant a standalone repository.
Each project is self-contained and includes its own `go.mod`.

# Сборник мини-проектов

Набор небольших программ на Go, которые не заслуживают отдельного репозитория.
Каждый проект автономен и имеет свой `go.mod`.
